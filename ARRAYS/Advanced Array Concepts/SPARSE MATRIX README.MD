# Sparse Matrix Representation in C

## 📌 Description
A sparse matrix is a matrix in which most of the elements are zero.  
To save memory, only non-zero elements along with their row and column indices are stored.

This program reads a matrix from the user and displays its sparse representation.

## 🎯 Objective
- To identify non-zero elements in a matrix
- To represent the matrix in sparse form (row, column, value)

## 🛠️ Algorithm
1. Read number of rows and columns.
2. Read all matrix elements.
3. Count the number of non-zero elements.
4. Display row index, column index, and value for each non-zero element.

## 💻 Program Features
- Simple and easy to understand
- Uses 2D arrays
- Efficient memory representation concept

## 📥 Input
- Number of rows and columns
- Matrix elements

## 📤 Output
- Sparse matrix representation
- Total count of non-zero elements
