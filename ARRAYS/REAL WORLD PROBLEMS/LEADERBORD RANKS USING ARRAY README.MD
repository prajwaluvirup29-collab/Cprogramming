# Find Leaderboard Ranks Using Arrays

## Aim
To determine the ranks of students based on marks using arrays in C.

## Description
The program stores student marks in an array, compares each student's marks with others, and assigns ranks accordingly.

## Key Concepts
- Arrays to store marks and ranks
- Nested loops for comparison
- Leaderboard computation

## Conclusion
Arrays allow easy storage and comparison for rank calculation among students.
