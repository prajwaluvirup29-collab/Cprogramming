# Histogram Frequency (Marks Distribution)

## Aim
To display the frequency distribution of marks as a histogram using arrays in C.

## Description
The program counts how many students scored each mark and prints a histogram using asterisks to represent frequency.

## Key Concepts
- Arrays for marks and frequency
- Counting frequency
- Simple histogram representation

## Conclusion
Histograms provide a visual representation of marks distribution and arrays make it easy to count frequencies.
