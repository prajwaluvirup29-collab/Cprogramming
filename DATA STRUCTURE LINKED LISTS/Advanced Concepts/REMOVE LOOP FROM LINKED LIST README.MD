# Remove a Loop from a Linked List

## Aim
To detect and remove a loop from a singly linked list.

## Algorithm
1. Detect loop using Floyd’s cycle detection.
2. Move one pointer to head.
3. Move both pointers one step at a time.
4. When next pointers match, break the loop.

## Output
Displays the linked list after loop removal.

## Time Complexity
O(n)
