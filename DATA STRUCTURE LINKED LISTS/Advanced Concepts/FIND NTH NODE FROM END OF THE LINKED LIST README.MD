# Find the Nth Node from the End of a Linked List

## Aim
To find the Nth node from the end of a singly linked list.

## Algorithm
1. Use two pointers: reference and main.
2. Move reference pointer N steps ahead.
3. Move both pointers until reference reaches NULL.
4. Main pointer will be at Nth node from end.

## Output
Displays the Nth node from the end.

## Time Complexity
O(n)
