# Insert into a Sorted Linked List

## Description
This program inserts elements into a singly linked list while maintaining ascending order.

## Algorithm
1. Create a new node.
2. If list is empty or value is smaller than head, insert at beginning.
3. Otherwise, find the correct position.
4. Insert the node.

## Time Complexity
O(n)

## Applications
- Maintaining ordered data
- Priority queues
