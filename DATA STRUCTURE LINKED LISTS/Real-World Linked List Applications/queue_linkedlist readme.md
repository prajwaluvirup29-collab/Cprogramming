# Queue Using Linked List

## Description

This project implements a Queue data structure using a singly linked list in C. Queue follows FIFO (First In First Out) principle.

## Operations

* Enqueue (Insert)
* Dequeue (Delete)
* Display

## Applications

* CPU scheduling
* Printer queue
* Task management systems

## Compilation

```
gcc queue_linkedlist.c -o queue
./queue
```
