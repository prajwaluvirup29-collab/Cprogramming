# Insert a Node at the End of a Singly Linked List

## Aim
To insert a node at the end of a singly linked list.

## Description
The program traverses the list to the last node and attaches the new node at the end.

## Concepts Used
- Linked list traversal
- Dynamic memory allocation
- Pointer operations

## Output
Displays the linked list after inserting the node at the end.
