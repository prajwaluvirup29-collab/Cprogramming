# Reverse Doubly Linked List

## 📌 Description
This program reverses the doubly linked list by swapping next and prev pointers of every node.

---

## 🚀 Features
- In-place reversal
- No extra memory required

---

## 🧠 Algorithm
1. Traverse list
2. Swap prev and next pointers
3. Move to next node
4. Update head
