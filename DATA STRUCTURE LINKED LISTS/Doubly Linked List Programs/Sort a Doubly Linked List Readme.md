# Sort Doubly Linked List

## 📌 Description
This program sorts the elements of a doubly linked list in ascending order using bubble sort technique.

---

## 🚀 Features
- Simple sorting method
- Works for any list size
- In-place sorting

---

## 🧠 Algorithm
1. Traverse list using two loops
2. Compare adjacent nodes
3. Swap data if needed
4. Repeat until sorted
