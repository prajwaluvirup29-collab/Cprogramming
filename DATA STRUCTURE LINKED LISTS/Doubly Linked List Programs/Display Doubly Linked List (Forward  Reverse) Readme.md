# Display Doubly Linked List (Forward & Reverse)

## 📌 Description
This program displays the elements of a doubly linked list in:

- Forward direction (head → tail)
- Reverse direction (tail → head)

---

## 🚀 Features
- Traversal using next pointer
- Reverse traversal using prev pointer
- Demonstrates bidirectional property

---

## 🧠 Algorithm

### Forward Display
1. Start from head
2. Print data
3. Move to next node
4. Repeat until NULL

### Reverse Display
1. Move to last node
2. Print data
3. Move using prev pointer
4. Repeat until NULL
