# Delete from Given Position in Doubly Linked List

## 📌 Description
Deletes a node from a specified position in the doubly linked list.

---

## 🚀 Features
- Delete head node
- Delete middle node
- Delete last node

---

## 🧠 Algorithm
1. Read position
2. Traverse to node
3. Update prev and next pointers
4. Free node memory
