# Create Doubly Linked List in C

## 📌 Description
This program creates a doubly linked list using dynamic memory allocation.  
Each node contains three fields:

- Data
- Pointer to Previous Node
- Pointer to Next Node

The user enters the number of nodes and values are inserted sequentially.

---

## 🚀 Features
- Dynamic node creation using malloc()
- Supports multiple node insertion
- Demonstrates pointer linking in both directions

---

## 🧠 Algorithm
1. Start
2. Read number of nodes `n`
3. Repeat `n` times:
   - Allocate memory for new node
   - Read data
   - If list empty → make it head
   - Else link previous node with new node
4. Stop
