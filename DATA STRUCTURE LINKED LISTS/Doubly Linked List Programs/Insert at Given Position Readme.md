# Insert at Given Position in Doubly Linked List

## 📌 Description
This program inserts a node at a specific position in the list.

Positions start from **1 (head position)**.

---

## 🚀 Features
- Insert at any valid position
- Handles insertion at beginning
- Maintains prev and next pointers

---

## 🧠 Algorithm
1. Read position
2. If position = 1 → insert at beginning
3. Traverse to position − 1
4. Insert node between nodes
5. Update pointers
