# Circular Linked List – Delete from Beginning and End

## Overview

This program removes nodes from the beginning and end of a circular linked list safely.

## Features

* Delete first node
* Delete last node
* Handles single-node case

## How to Compile and Run

```bash
gcc delete_circular.c -o delete
./delete
```

## Example

Before: 10 → 20 → 30 → 40
After deletion: 20 → 30

## Concepts Used

* Memory deallocation
* Pointer updates
