# Josephus Problem – Circular Linked List

## Overview

This program solves the Josephus problem using a circular linked list. It eliminates every k-th person until one survivor remains.

## Features

* Simulation of elimination process
* Displays survivor position

## How to Compile and Run

```bash
gcc josephus.c -o josephus
./josephus
```

## Example

Input: n = 7, k = 3
Output: Survivor = 4

## Concepts Used

* Circular traversal
* Problem simulation
