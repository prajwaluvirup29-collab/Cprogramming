# Circular Linked List – Traversal

## Overview

This program traverses a circular linked list and displays all elements starting from the head node until it reaches the head again.

## Features

* Traversal without infinite loop
* Displays all node values

## How to Compile and Run

```bash
gcc traverse_circular.c -o traverse
./traverse
```

## Example

Output: 10 → 20 → 30 → 40 → (back to head)

## Concepts Used

* Loop termination condition in circular structures
* Pointer iteration
