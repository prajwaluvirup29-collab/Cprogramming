# Circular Linked List – Split into Two Halves

## Overview

This program splits a circular linked list into two equal halves using the slow and fast pointer technique.

## Features

* Splits list into two circular lists
* Works for even and odd node counts

## How to Compile and Run

```bash
gcc split_circular.c -o split
./split
```

## Example

Original: 1 → 2 → 3 → 4 → 5 → 6
Split:

* List 1: 1 → 2 → 3
* List 2: 4 → 5 → 6

## Concepts Used

* Two-pointer technique
* Circular list manipulation
