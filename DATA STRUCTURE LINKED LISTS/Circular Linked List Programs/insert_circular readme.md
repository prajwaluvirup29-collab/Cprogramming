# Circular Linked List – Insert at Beginning and End

## Overview

This program inserts nodes at both the beginning and the end of a circular linked list while maintaining circular connectivity.

## Features

* Insert at beginning
* Insert at end
* Maintains circular structure

## How to Compile and Run

```bash
gcc insert_circular.c -o insert
./insert
```

## Example

List after insertion: 5 → 10 → 20 → 30

## Concepts Used

* Head pointer updates
* Last node linking
