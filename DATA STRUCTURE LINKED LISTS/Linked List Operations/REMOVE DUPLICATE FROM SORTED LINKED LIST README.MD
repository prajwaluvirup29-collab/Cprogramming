# Remove Duplicates from a Sorted Linked List

## Aim
To remove duplicate elements from a sorted singly linked list.

## Algorithm
1. Traverse the list using a pointer.
2. If current node data equals next node data:
   - Delete the next node.
3. Otherwise move to next node.
4. Continue until end of list.

## Output
Displays the linked list after removing duplicate elements.

## Time Complexity
O(n)
