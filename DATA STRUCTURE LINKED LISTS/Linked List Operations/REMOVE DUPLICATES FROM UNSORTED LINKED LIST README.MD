# Remove Duplicates from an Unsorted Linked List

## Aim
To remove duplicate elements from an unsorted singly linked list.

## Algorithm
1. Use two pointers:
   - Current pointer
   - Runner pointer
2. Compare current node with all subsequent nodes.
3. If duplicate is found, delete the node.
4. Repeat until the end of the list.

## Output
Displays the linked list after removing duplicates.

## Time Complexity
O(n²)
