# Check Whether a Linked List Is Sorted

## Aim
To check whether the elements of a singly linked list are in ascending order.

## Algorithm
1. Traverse the linked list.
2. Compare current node data with next node data.
3. If any node is greater than the next node, list is not sorted.
4. If traversal completes, list is sorted.

## Output
Displays whether the linked list is sorted or not.

## Time Complexity
O(n)
