# C Programming & Data Structures Using C — Program Repository

Welcome to my repository!
This project contains a comprehensive collection of programs developed while learning **C Programming** and **Data Structures Using C**.
It demonstrates my understanding of core programming concepts, problem-solving skills, and practical implementation of data structures such as **Arrays** and **Linked Lists**, including real-world applications.

The repository is organized systematically to cover concepts from fundamentals to advanced implementations.

# Topics Covered

## C Programming Fundamentals

* Input and Output operations
* Conditional statements and loops
* Functions (pass by value and reference)
* Recursion concepts
* Pointers and memory handling
* Structures and user-defined data types
* Dynamic memory allocation

## Arrays

The repository includes a wide range of array-based programs such as:

* Array declaration, initialization, traversal
* Sum, average, maximum and minimum elements
* Counting positive, negative, even, and odd numbers
* Searching techniques (Linear Search, Binary Search)
* Sorting algorithms (Bubble, Selection, Insertion)
* Frequency counting and duplicate removal
* Finding second largest/smallest and kth elements
* Array rotations and prefix sums
* Merging and comparing arrays
* Mathematical operations on arrays
* Real-world applications (marks analysis, rankings, histogram, statistics)

## Multidimensional Arrays (Matrices)

Programs covering matrix concepts including:

* Matrix input and output
* Matrix addition, subtraction, multiplication
* Matrix transpose and symmetry check
* Row and column operations
* Diagonal operations
* Wave (zig-zag) printing
* Searching elements in 2D matrices
* Sparse matrix representation
* Dynamic and jagged arrays using pointers

## Linked Lists

Implementation of various linked list concepts:

* Singly linked list operations (creation, insertion, deletion, traversal)
* Searching, counting nodes, sorting lists
* Reversing linked list (iterative and recursive)
* Merging, splitting, copying, concatenation
* Duplicate removal and sorted list checking
* Advanced operations (loop detection, nth node from end, node swapping, rotation)

## Doubly Linked Lists

* Creation and traversal (forward and reverse)
* Insertion and deletion operations
* Reversing and sorting doubly linked lists
* Navigation-based implementations

## Circular Linked Lists

* Creation and traversal
* Insertion and deletion operations
* Splitting circular lists
* Josephus problem implementation

## Real-World Data Structure Applications

Practical implementations demonstrating real-life usage:

* Queue using linked list
* Stack using linked list
* Polynomial addition
* Sparse matrix using linked list
* Student record management system
* Browser forward/backward navigation using doubly linked list
* Music playlist simulation using circular linked list
